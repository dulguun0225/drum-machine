# Drum Machine

The project builds one self-contained static HTML file (dist/index.html) with all JS and CSS inlined; no change may break that constraint.

## Commands

- `mise exec -- vp dev`: start the dev server
- `mise exec -- vp build`: build dist/index.html
- `mise exec -- vp test`: run Vitest tests
- `mise exec -- vp check`: format, lint, and type check
